# 后台直发适配调查与未完成项

核查日期：2026-10-19。目标是已有普通微信账号，在群中发文字和真实文件；无需窗口、焦点、按键、剪贴板或 CU。当前主机版本为 Windows 微信 4.1.15.51。读取路径已独立于界面。

截至本次核查，没有获得可确认适配 4.1.15.51、能同时发文字和文件、且可审查和发布的后台引擎。此结论是本次调查范围，不是“技术上不可能”或“全网不存在”。没有安装 Hook、修改当前微信、降级、重新登录或向外部 SDK 上传账号数据。

HTTP/MCP 包装不是底层发送能力。数据库读取成功也不能推出能够构造有效的发送请求。向数据库插入一条记录不能发送到微信服务器，因此本项目不会将写库当作发送方案。

## 后续实现必须完成

1. 对准确客户端版本与 DLL 哈希建立可复现的发送 ABI、线程调度及生命周期适配。旧版本裸偏移不可猜测复用。
2. 文字通过客户端内部发送调用；文件完成真实上传、附件元数据和发送调用，不能用卡片链接或文件路径冒充文件。
3. 本地传输绑定当前进程和账号，保留稳定 ID 白名单、附件哈希、串行出站、持久幂等以及失败后不自动重发。
4. 接口返回“已受理”不等于成功。用原有只读消息源和监听核对本人发出记录；在版本固定的测试环境验证接收侧内容。
5. 只向明确授权的测试群和文件传输助手做真实验收；同时证明没有窗口操作、焦点变化或剪贴板写入。

当前发布版不含伪造的后台实现、未经核查的注入器或空 RPC 占位适配器。发送能力显式为 false。未达到完整项目验收，也未达到用户要求的真实文字、文件、监听闭环。
